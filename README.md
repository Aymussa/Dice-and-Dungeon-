This is a Dice and Dungeons game base where you roll a dice to determine the outcome of your story.

## Features
- Dice rolling
- Story outcomes
- Name input

## How to Run
1. Clone the repository
2. Open the repository in your preferred IDE
3. Compile the Game.java file
4. Run the Game.java file
5. Follow the prompts
